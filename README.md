# kakeibo-pwa

家計簿システム「kakeibo」のPWA 2本(GitHub Pages配信用・Public)。

| パス | アプリ | 役割 |
|---|---|---|
| `/`(ルート) | kakeibo(カメラ) | レシート撮影 → GAS Web APIへ送信(2タップ) |
| `/fintrack/` | FinTrack(ビューア) | 明細DBの閲覧専用。ホーム/取引/分析の3画面、編集機能なし |

- 各フォルダに独自manifest(`scope`分離)があり、**別アプリとして共存インストール**できる
- GAS WebアプリURLは**このリポジトリに含めない**。初回に `?gas=<WebアプリURL>` 付きで
  一度開くと localStorage に保存され、以後は不要(URLは即座にアドレスバーから消える)。
  両アプリは同一オリジンなので設定は共有される(片方で設定済みならもう片方は不要)
- 本体(GAS・移行スクリプト・設計書)は別リポジトリ `kakeibo`(Private)で管理

## スマホへの導入手順

1. Chromeで `?gas=...` 付きURLを開く(URLは所有者のみが知る。FinTrackはカメラ版設定済みなら素のURLでOK)
2. カメラ許可を求められたら許可(カメラ版のみ)
3. メニュー →「ホーム画面に追加」
4. カメラ版: アイコンから起動 → 撮影 → 「登録完了。閉じてOK」で完了 / FinTrack: 起動すると今月のサマリーが即表示
